# Extensions

Extensions and Lua support are planned. The Kotlin editor currently ships with bundled TextMate grammars and a per-tab language picker.

## Current availability

The Kotlin build has no extension manager, Lua runtime, or documented extension API. For now, use the built-in [language modes and workbench controls](/docs/).
